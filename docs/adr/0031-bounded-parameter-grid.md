# ADR-0031 — Preregistered bounded parameter grid

Status: Proposed; CI pending.

Begin with finite deterministic ORB Cartesian grids, explicit candidate and full matched replay budgets, no adaptive feedback or optimization of risk/capital. Canonical manifest pins full grid, scenario, fold plan and diagnostic policies into registered context. Reuse E5 and matched baselines; return all assessments and failures. No automatic selection or holdout access. Trial lineage, multiple-testing discipline and verified market data remain open. See [E6.5a](../E6_5A_PARAMETER_SEARCH.md).
