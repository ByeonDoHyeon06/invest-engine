# ADR-0032 — Durable local validation search claims and descriptive stability

Status: Proposed; CI pending.

Reserve immutable search manifest, arm budget and stability policy before evidence; reject overlapping validation claims in the same journal, using tape hash and stable instrument intervals. Persist full canonical outcome matrices including failures, with exact evidence report identities. Identical retry is idempotent; no claim of counting crashed or repeated identical physical executions. Select only after latest full recorded matrix and ordinary validation gates plus temporal-block stability. Group overlapping UTC days across instruments, paired worse-cost excess and leave-one-block-out diagnostic; no independence, significance or multiple-testing correction claim. No holdout access or production authority. See [E6.5b](../E6_5B_SEARCH_LINEAGE.md).
