# ADR-0028 — Fixed-rule fold execution and preregistered E5 identities

Status: Proposed; CI pending.

Use complete strict E5 windows with fresh fixed ORB and matched baseline strategies, not new synthetic fill code. Require exact eligible validation sample/observation identities and the full fold/instrument matrix; a purged sample blocks a strict window. Bind every arm's E5 configuration before replay in the common registered window context; record reconciled provisional reports in existing durable research journal. No supervised training, holdout data acceptance or promotion. Per-arm runtime failures reported without fabricated returns. See [E6.3b](../milestones/e6/E6_3B_FOLD_EXECUTION.md).
